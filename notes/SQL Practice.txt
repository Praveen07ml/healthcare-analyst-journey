Customers
Orders
Order_Items
Products

Manual Verification - we have to check whether that customer purchased two different products categories
Business Proof -  counting + grouping  + having
SQL Pattern



SELECT c.customer_name,count( DISTINCT p.category_id) as category_count
FROM customers c
JOIN orders o on o.customer_id = c.customer_id
JOIN order_items o1 on o1.order_id = o.order_id
JOIN products p on p.product_id = o1.product_id
GROUP by c.customer_id,c.customer_name

Categories

Manual Verification - we have to check and  return customers that customer must buy all products in mobile category or not
Business Proof group by + having + sub queary comparision
SQL Pattern



SELECT c.customer_name,count(distinct p.product_id) as order_count
FROM customers c
JOIN orders o on o.customer_id = c.customer_id
JOIN order_items o1 on o1.order_id = o.order_id
JOIN products p on p.product_id  = o1.product_id
JOIN categories c on c.category_id = p.category_id
WHERE cat.category_name = 'Mobile'
GROUP by c.customer_id,c.customer_name
HAVING count(distinct p.product_id) = (SELECT count(p.product_id) FROM products p
                                       JOIN categories c on c.category_id = p.category_id
									   WHERE c.category_name = 'Mobile');
