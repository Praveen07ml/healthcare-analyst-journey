Business Requirement

Display the names of customers whose total spending is greater than ₹50,000.

Tables

Customers
Orders

Answer in this format only:



Business Requirement-- we have to display customers their total spending greater than 50k
Manual Verification -- we need to solve total spending table and filter the result with 50 k
Business Proof - group by + having +sum total amount inside derived table
Why do we need a Derived Table here? -- because we need not have total spending column in actual tables so we have to create one use it for main query
SQL

SELECT t.customer_name
FROM (SELECT c.customer_name,sum(o.total_amount) as total_spending
      FROM customers c
	  JOIN orders o
	  on o.customer_id = c.customer_id
	  GROUP by c.customer_name) t
WHERE t.total_spending > 50000;

-- Display the names of customers who have purchased at least 10 different products.


SELECT t.customer_name
FROM (SELECT c.customer_name,count(DISTINCT o1.product_id) as product_count
      FROM customers c
	  JOIN orders o
	  on o.customer_id = c.customer_id
	  JOIN order_items o1 on o1.order_id = o.order_id
	  GROUP by c.customer_id,c.customer_name) t

Display the names of customers who purchased products from every category.

Orders

Business Requirement -- we need to find customers ppurcahse from every category
Manual Verification  -- so  we need to look into each customer purchase categories satisfy all categories
Business Proof -- we need to calculate count of disctinct categories that customer brought and return customers who brought equally the whole count categories 
SQL


-- Display the names of customers who purchased products from every category.


SELECT t.customer_name
FROM (SELECT c.customer_name,count(distinct p.category_id) as customer_cat_count
      FROM customers c
	  JOIN orders o
	  on c.customer_id = o.customer_id
	  JOIN order_items o1 on o1.order_id = o.order_id
	  JOIN products p on p.product_id = o1.product_id
	  GROUP by c.customer_id,c.customer_name) t
where t.customer_cat_count = (SELECT count(*)
                              FROM categories);




Display the names of customers whose average order amount is greater than ₹7,500 and who have never placed an order below ₹500.

Orders

Manual Verification  - we need to check the customer avg order value > 7.5 k and never place order < 500
Business Proof - we have to calculate avg order value and never palced order below and return customers to filter out them based on conditions
SQL


SELECT customer_name
FROM (SELECT c.customer_name,o.total_amount,avg(o.total_amount) as avg_amount
      FROM customers c
	  JOIN orders o
	  on o.customer_id = c.customer_id
	  GROUP by c.customer_id,c.customer_name,o.total_amount) t
